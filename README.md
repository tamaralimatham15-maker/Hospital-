# رِعاية – CareFlow

نسخة تجريبية أولية لتطبيق إدارة المستشفيات والردهات والمرضى والعلاجات.

هذه النسخة تستخدم بيانات محلية تجريبية فقط، ولا تتصل بخادم أو قاعدة بيانات. لا تستخدم بيانات مرضى حقيقية ولا تعتمد عليها في الرعاية السريرية.

## بناء APK
يتم البناء عبر GitHub Actions بعد إضافة ملفات Flutter المطلوبة.
